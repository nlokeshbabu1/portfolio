# Resume

Place the resume PDF at exactly this path:

```
public/resume/Lokesh_Babu_Resume.pdf
```

The website's "Download Resume" button links to `/resume/Lokesh_Babu_Resume.pdf`
(the file is copied to `dist/resume/` during `npm run build`).

The filename is case-sensitive in production — keep it exactly
`Lokesh_Babu_Resume.pdf`.
